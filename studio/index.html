Texture overlay
The overlay is applied per image: every entry in the firmware's own index gets the whole texture fitted to its own frame, so a sheet of icons comes out looking like a set rather than like a strip cut at random. Artwork the index does not cover is taken a region at a time, since inside a region nothing says where one picture ends. Multiply keeps the artwork's shading and reads as a tint, opacity mixes the result back into the colour that was there — 30% recolours without erasing the drawing — and keep alpha leaves every silhouette intact and changes only the colour beneath it.
Image boundaries in the firmware are not labelled, so offset, width and height are estimates — nudge them until the tiles line up, then click one to replace it. Offset is free-form hex, so you are not limited to the detected regions. Auto re-estimates the stride at wherever you are; ±row shifts by one row so you can walk an image into alignment. Keep alpha byte copies the third byte of every pixel from the original, which preserves icon shapes and anything else encoded there; turn it off only deliberately. Shift+click a tile to replace it from Valeton Suite's own artwork — the same images at far higher resolution than the firmware carries. icons (auto) splits the region into separate images at the blank rows between them and shows each one framed — a region rendered as one continuous strip reads as torn garbage, because the strip glues unrelated images together and runs on into whatever non-image data follows. Click an icon to load its exact offset and height.
Screen
320×240, the pedal's screen, at 2×. Drag an asset in from the list; drag it about to compose. The pedal's own layout is not in the firmware — where each widget sits is decided by the application code, which lives in SDRAM and is not mapped in the file. So this canvas is where you arrange things to work on them; what it writes back is the artwork itself, in its own slot, at its own size.

Recolour keeps the drawing and moves its colours: hue turns the wheel, tint pulls everything towards one colour. That is how a whole interface changes theme without anything being redrawn.
Assets
Only runs that look like real text and sit among other strings are listed — the firmware is full of printable byte sequences that are not text at all. Edits are written in place; the room column is the hard limit in bytes. Enter в строке — применить её. «Заменить» меняет подстроку только в текущем совпадении (подсвечено), «Заменить все» — во всех найденных. Строка, которая после замены не влезает в room, пропускается и попадает в отчёт.

        The pedal's own UI font is not in this file — not as 1-bit glyphs, not
        as an anti-aliased sheet, not behind a glyph-descriptor table. Every 32 KB of the
